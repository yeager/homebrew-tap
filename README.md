# Yeager Homebrew Tap

Homebrew formulae for [Yeager](https://github.com/yeager) tools.

## Installation

```bash
brew tap yeager/tap
brew install vsdview
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| vsdview | Read-only viewer for Microsoft Visio files (.vsdx/.vsd) |
